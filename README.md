# 🎯 The Perfect Guess Game

A fun Python-based number guessing game with a graphical user interface (GUI) and voice feedback. The player must guess a randomly generated number between 1 and 100, and the game provides hints until the correct number is guessed.

## 🚀 Features

- 🎨 User-friendly GUI built with Tkinter
- 🔊 Voice feedback using pyttsx3
- 🎲 Random number generation
- 📈 Attempt counter
- ✅ Input validation
- 🎉 Winner pop-up message

## 🛠️ Technologies Used

- Python 3
- Tkinter
- pyttsx3

## 📦 Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/the-perfect-guess.git
```

2. Navigate to the project directory:

```bash
cd the-perfect-guess
```

3. Install the required package:

```bash
pip install pyttsx3
```

## ▶️ How to Run

Run the Python file:

```bash
python perfect_guess.py
```

## 🎮 How to Play

1. Launch the game.
2. Enter a number between 1 and 100.
3. Click the **Guess** button.
4. Follow the hints:
   - Too High
   - Too Low
5. Keep guessing until you find the correct number.
6. The game will announce your victory and display the number of attempts.
